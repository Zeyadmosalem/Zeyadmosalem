### About

I write automated tests that catch real bugs, from Postgres security policies up
to the browser, and I run them in CI so nothing broken ships.

I test access control the way an attacker would: red-team suites that try to
escalate privileges or read data a role shouldn't see, and fail the build if they
succeed. Across my projects, that's more than **2,900 automated tests** running on
every push.

I also build the apps I test, in React, TypeScript and Supabase, so I can read the
code, find the root cause and write a bug report a developer can act on. I use AI
coding tools like Claude Code to move faster, while owning the test strategy and
the quality.

Computer Science student at **E-JUST**, Alexandria, Egypt (graduating December 2027).
Available for remote part-time and contract QA automation work, up to 20 hours a week.

### Featured work

#### [NC Spark](https://github.com/Zeyadmosalem/nc-spark)

**1,828 tests at 91% statement coverage, including red-team security suites.** A
role-based compliance training platform with four portals and seven authorable
activity types. The suites try to escalate privileges and leak the quiz answer key,
which lives in a table no browser role has a grant on and is reachable only from an
Edge Function. The tests prove that three independent layers block escalation, and
that XP, streaks and badges always agree with the single append-only ledger they
derive from.

React 19 · Vite 8 · Supabase / Postgres 17 · Cloudflare Workers
**1,828 tests · 91% statement coverage · red-team security suites**

#### [Samboza](https://github.com/Zeyadmosalem/Samboza) — in production

**532 pgTAP policy tests proving who can read and write which rows.** A bilingual
household finance PWA in daily use since September 2026, where Postgres row-level
security, not the screen, enforces access across four roles. Its CI pipeline runs
578 front-end tests on every push and refuses to deploy until the database has
every migration the bundle expects, covering the double-entry ledger, the audit
trail and offline writes through an idempotent outbox.

React 19 · TypeScript · Supabase / Postgres · Cloudflare Workers · GitHub Actions
**532 pgTAP policy tests · 578 front-end tests · 50 migrations gated in CI**

#### [Beyond Seen Mistakes](https://github.com/AbdelrahmanAboegela/beyond-seen-mistakes) — test & CI contributor

**I wrote the test suite and CI for a published research pipeline.** It covers
data loaders, the split protocol, training edge cases and reproduction checks. I
also fixed the reproduction checks to compare results numerically instead of
bit-for-bit, which made them reliable across machines. The project is the source of
the JAC-ECC 2026 HAR–EAS submission, which stress-tests six models, including ST-GCN
and FACT.
